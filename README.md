## 📌 نظرة عامة

تطبيق ويب تفاعلي مصمم لموظفي المحاكم في المملكة العربية السعودية، يُبسّط عملية الرد على استفسارات المستفيدين من خلال ثلاث مراحل متسلسلة: **تحليل الرسالة الواردة** — **استخراج المواد النظامية ذات الصلة** — **صياغة رد رسمي احترافي**.

## 🖥️ آلية العمل

التطبيق يسير وفق تدفق منطقي في أربع مناطق:

```
1. 📝 رسالة المستفيد    ──▶  الصق الرسالة الواردة
           │
           ▼
2. 🔍 تحليل + مواد      ──▶  استخراج الموضوع + المواد النظامية تلقائياً
           │
           ▼
3. ✍️ كتابة الرد        ──▶  اكتب بأسلوبك ← ثم حسّن الصياغة
           │
           ▼
4. 📤 الرد النهائي      ──▶  نسخ / حفظ / أرشفة
```

## 🚀 التشغيل

### المعاينة المباشرة

```
https://abosalehg-ui.github.io/legal-assistant/
```

### التشغيل المحلي

```bash
# استنساخ المستودع
git clone https://github.com/abosalehg-ui/legal-assistant.git
cd legal-assistant

# تشغيل خادم HTTP بسيط (مطلوب لتحميل ملفات JSON)
python3 -m http.server 8000
# ثم افتح المتصفح على: http://localhost:8000
```

> ⚠️ نظراً لاستخدام ES Modules و `fetch()` لتحميل البيانات، فتح الملف مباشرة بـ `file://` لا يعمل في معظم المتصفحات بسبب CORS. استخدم خادماً محلياً (Python أو Node أو أي بديل) أو افتح النسخة المنشورة على GitHub Pages.

## 🛠️ التقنيات المستخدمة

* **HTML5** — هيكلة الواجهة ودعم RTL
* **CSS3** — التصميم والتنسيق مع متغيرات للوضع الفاتح/الداكن
* **JavaScript (ES Modules)** — منطق التطبيق مقسّم على وحدات بدون أي build step
* **JSON** — قاعدة بيانات المواد والقوالب قابلة للتحرير المباشر
* **Service Worker + Web App Manifest** — عمل دون اتصال وقابلية التثبيت (PWA)
  * cache-first للأصول الثابتة (إقلاع فوري) و stale-while-revalidate للمستند وملفات البيانات
* **خطوط مستضافة ذاتياً** — Tajawal وAmiri دون طلبات لأي طرف ثالث
* **node:test + jsdom + ESLint + Prettier + GitHub Actions** — اختبارات وفحص جودة وتكامل مستمر

## 🧪 التطوير والاختبار

